# rules/ — 디자인 시스템 규칙 (공개 제외)

원래 이 폴더에는 `/dsys`(Design System Agent)가 기업 Figma에서 추출한 두 파일이 있습니다.

- `design-system.md` — 색상·타이포·간격·radius·shadow 토큰
- `design-application.md` — 레이아웃·반응형·타이포 클래스·컴포넌트별 스펙

기업의 디자인 시스템은 대외비라서 공개 저장소에는 포함하지 않았습니다.
다른 프로젝트에서 쓰려면 그 프로젝트의 Figma 디자인 규칙 node를 입력으로 `/dsys`를 실행해 두 파일을 새로 만드세요.
나머지 에이전트는 이 두 파일을 읽기만 하므로, 파일이 없으면 `/build`·`/qa` 단계에서 오류가 나거나 결과가 불완전할 수 있습니다.
