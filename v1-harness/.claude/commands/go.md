`.claude/CLAUDE.md`(공통) → `.claude/agents/orchestrator-agent.md`를 읽고 그 자동 진행 루프를 따른다.

## 인자 있음 (`/go SVA-05`) — `타입`=디자인시스템이면 "사람이 `/dsys {번호}` 직접" 안내 후 종료
1. DB 「파이프라인 태스크 (v2)」(`collection://<YOUR_NOTION_DB_ID>`)에서 `$ARGUMENTS`(상위번호) 조회. 없으면 중단.
2. 하위 태스크가 없으면 → `타입` 판정표로 하위 N개를 생성한다 (`{번호}-1` ~ `{번호}-4`, `{번호}-D`). 입력물에 이미 있는 산출물에 해당하는 하위는 "완료"로.
3. **자동 진행 루프:** 다음 미완료 하위 → 그 커맨드 실행 (`/spec` `/screen` `/build` `/qa`) → 하위 완료 처리 → 상위 `➡️ 다음 실행` 갱신 → 다음 하위로 반복.
4. **멈춤 지점**(orchestrator-agent.md 표) 만나면 정지하고 보고:
   - `-D` 하위 Figma URL 빔 → "Figma 링크 기입 후 `/go {상위}`"
   - `/spec` 누락 6건↑ → 질문
   - `/screen` 정책 모순 → 질문
   - `/qa` FAIL → `/build` 1회 자동 재시도 → 또 FAIL이면 정지
5. 모든 하위 완료 → 상위 `현재 단계`=완료.

## 인자 없음 (`/go`)
`현재 단계`≠완료인 **상위 태스크** 전부 조회 → 각 `➡️ 다음 실행`·하위 진행 상황 표로 브리핑. 실행하지 않는다.

## 출력
- (인자 有) 자동 실행한 하위 단계 목록 + 각 산출물 + 정지 지점과 필요한 사용자 액션
- (인자 無) 진행 중 상위 태스크 현황 표
