`.claude/CLAUDE.md` → `.claude/agents/task-agent.md`를 읽고 그 사고 순서를 따른다.

1. `$ARGUMENTS`(요청)에서 프로젝트·타입·입력물·Figma URL을 파싱한다.
2. DB `collection://<YOUR_NOTION_DB_ID>`에서 같은 프로젝트 마지막 번호를 조회해 다음 번호를 정한다 (`SVA`/`SVB`/`COM`).
3. DB에 **상위 태스크** 행을 생성한다 (`현재 단계`=시작 전, `➡️ 다음 실행`=`/go {번호}`).
4. 복수 화면/기능 요청이면 상위 태스크를 단위별로 여러 개.
5. **생성 직후 각 상위 번호에 대해 `/go {번호}`를 실행한다.** Orchestrator가 하위 태스크를 만들고 멈춤 지점까지 자동 진행한다.

## 출력
- 생성한 상위 태스크: 번호 · 태스크명 · 타입
- 이어서 실행한 `/go`의 진행 요약 (자동 완료된 단계 + 정지 지점)
